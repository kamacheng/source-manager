# 路径过滤关键词功能设计文档

**日期：** 2026-03-13
**状态：** 已确认
**所属模块：** 客户端内置资源 → 读取本地资源

---

## 背景

用户点击「读取本地资源」选中本地目录后，当前会将目录下所有文件信息全量导入。当本地目录结构复杂时，用户只需要导入特定子目录下的文件，全量导入会引入大量无关文件，干扰后续操作。

---

## 目标

允许用户配置一组路径过滤关键词，扫描时只导入路径中包含指定目录名的文件，其余文件忽略。

---

## 功能描述

### 过滤规则

- 关键词与文件的相对路径各路径段进行精确匹配（以 `/` 分割路径后逐段比对）
- 多个关键词之间为**并集**关系：路径中任意一段匹配任意一个关键词，即纳入结果
- 关键词列表为空时，不做过滤，全量导入

**示例：**
关键词为 `ui`、`audio`，文件路径 `assets/ui/button.png` → 匹配（含 `ui` 段）
文件路径 `assets/build/guide.png` → 不匹配（无 `ui` 或 `audio` 段）

### 关键词存储

- 演示阶段：存储于浏览器 `localStorage`，key 为 `pathFilterKeywords`，格式为字符串数组
- 正式上线时应改为后端 API 存储，作为全局配置由所有用户共享

---

## UI 交互

### 新增「路径过滤」按钮

- 位置：「读取本地资源」按钮左侧
- 样式：使用漏斗图标，有关键词时显示数字角标（如 `3`），无关键词时不显示角标
- 功能：点击打开「路径过滤设置」弹窗

### 路径过滤设置弹窗

| 区域 | 内容 |
|------|------|
| 顶部说明 | 「只导入路径中包含以下目录名的文件，留空则全量导入」 |
| 关键词列表 | 每个关键词为一个 tag，右侧有删除按钮；列表为空时显示占位提示「暂无关键词，将全量导入」 |
| 底部输入区 | 文本输入框 + 「添加」按钮，支持回车添加，自动去除首尾空格，忽略重复关键词 |
| 操作按钮 | 「确定」按钮，点击关闭弹窗，立即生效 |

### 扫描结果弹窗（本地文件夹信息）

- 有关键词时，标题区显示：`命中 X 个文件（共扫描 Y 个）`
- 无关键词时，标题区显示：`共 Y 个文件（未过滤）`

---

## 不在本次范围内

- 关键词排序或分组
- 关键词的导入/导出
- 正则表达式或通配符支持
- 路径过滤应用于「后台上传资源」视图
